# Screenshot Capture Guide

This release uses screenshot placeholders. Replace them with real captures using this checklist.

## Output folder convention

Store images under `apps/docs/docs/assets/screenshots/` using these names:

- `getting-started-create-project.png`
- `core-project-overview.png`
- `core-task-composer.png`
- `core-task-follow-up.png`
- `core-files-browser.png`
- `core-connectors.png`
- `core-notifications.png`

## Capture rules

- Use light theme unless a dark-mode interaction is specifically important.
- Keep browser zoom at 100%.
- Hide personal or secret data.
- Capture at desktop width around 1440px.
- Ensure highlighted UI element is visible and unobstructed.

## Review checklist

- filename matches placeholder exactly,
- image clearly shows action context,
- no sensitive data visible,
- markdown page updated to embed the final image.
