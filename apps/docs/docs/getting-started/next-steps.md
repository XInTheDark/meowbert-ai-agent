# Next Steps

You've set up a project and run your first task. Here's how to get the most out of Meowbert going forward.

## Develop a daily routine

1. **Open Project Overview** and scan for queued or running tasks before starting new ones. Use filters to focus on `running` and `awaiting_input` states.
2. **Write outcome-oriented prompts.** Start with what you want, include constraints (format, deadline, style), and attach relevant files when useful.
3. **Inspect artifacts before sharing.** Open the Files browser to review generated outputs. Download or preview files before forwarding results to colleagues.
4. **Use notifications** to track background tasks. Enable notifications so you're alerted when a long-running task completes even if you've switched tabs or windows.

If your team works in Telegram, Discord, or GitHub, setting up a connector means anyone on the team can trigger tasks from their preferred tool. See the [Connectors Overview](/core-workflows/connectors) page to decide which integration fits best.
