# Workspace Navigation

The sidebar is your main navigation surface. This page walks through every part of it so you can move around confidently.

## Switching workspaces

At the top of the sidebar is the **Workspace selector** — a dropdown showing the name of your current workspace. Click it to:

- Switch to a different workspace.
- Open workspace management (members, settings).
- Create a new workspace if you have permission.

If you're a member of only one workspace, you'll land there automatically on login.

## Workspace-level sections

These sections appear regardless of which project is selected:

| Section | What it does |
|---|---|
| **All Projects** | Lists every project in the workspace. Click one to enter it. |
| **Connectors** | Manage Telegram, Discord, and GitHub integrations. |
| **Notifications** | See task event alerts and configure browser push notifications. |
| **Subscription** | View usage, limits, and billing information. |

## Project-level sections

Once you open a project, its tabs give you access to project tools. The workspace sidebar stays available:

| Section | What it does |
|---|---|
| **New Task** | Opens the Task Composer for this project. |
| **Tasks** | Shows the task list with status, filters, and bulk controls. |
| **Files** | Browse, upload, and download files in the project filesystem. |
| **Context** | Manage reference files shared with tasks. |
| **Canvases** | Open and manage interactive outputs. |
| **Settings** | Edit project name, status, personality, and default context. |

## Returning to the workspace level

Click **All Projects** in the sidebar at any time to go back to the workspace-level view and pick a different project.

## Keyboard shortcuts and tips

- The sidebar collapses on narrow viewports — use the menu icon to expand it.
- Your last-visited project is remembered between sessions.
- Deep links (e.g., a direct URL to a task) open the correct workspace and project automatically.
