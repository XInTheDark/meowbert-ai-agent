# Computer Use

Computer Use lets Meowbert take actions directly on your desktop computer. When enabled on a task, the agent can move the mouse, click, type text, scroll, and take screenshots — all orchestrated from within the task conversation.

::: info Desktop app required
Computer Use is only available when you're running the **Meowbert Desktop** app. It cannot be used from the browser.
:::

## Enabling Computer Use

Open the **Task Composer** and click the **Tools** dropdown. Toggle **Computer Use** on. You'll see a confirmation prompt explaining what this allows before any actions are taken.

Once enabled, the agent will see a live view of your screen after each action so it can observe the result and decide what to do next.

## What the agent can do

| Action | Description |
|---|---|
| **Screenshot** | Capture the current state of the screen |
| **Mouse move** | Move the cursor to a position |
| **Click** | Left, right, or double-click at a coordinate |
| **Type** | Type text into the focused input |
| **Scroll** | Scroll up or down at a position |
| **Key press** | Press keyboard shortcuts or special keys |

## Permission prompts

Before any computer action runs, a permission dialog appears so you can review what Meowbert is about to do. You can approve, skip an individual action, or stop the task entirely.

## Tips

- Close or minimize sensitive windows before starting a computer-use task.
- Use a dedicated task description so the agent stays focused on the right application.
- You can always pause or cancel a task mid-run from the Task Detail view.
