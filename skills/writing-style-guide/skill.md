# Writing Style Guide

Your base instructions contain the writing rules that apply everywhere. The guides in this folder add the conventions and examples for one kind of writing each. Read the one that matches the deliverable:

- `teaching.md`: course notes, tutorials, and study guides
- `reports.md`: reports, analyses, research write-ups, and notebooks that present findings
- `technical-docs.md`: READMEs, setup guides, configuration references, PR descriptions, and changelogs
- `work-messages.md`: emails, status updates, and announcements
- `public-writing.md`: social posts, bios, cover letters, and other writing in the user's own voice
- `editing.md`: revising writing the user already has, such as papers, essays, and docs

In every example, the preferred version keeps the original facts and limitations. Only the writing changes.

When the user asks you to humanize writing or make it sound less like AI, read `../humanize/skill.md`, which overrides some of these rules for that text.
