# Your Chrome

Use this skill for sites that need the user's saved logins. It opens the installed Chrome, or Edge if Chrome is unavailable, with a dedicated persistent Meowbert profile. The browser is visible so the user can watch and take over. Logins persist across tasks.

Only one task can use this browser at a time. If another task owns it, wait for it to finish. Browser Use inside the sandbox is separate and can still be used for headless browsing.
