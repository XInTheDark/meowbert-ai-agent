Use this source when the workspace has connected Google Drive.

Capabilities:
- Search Google Drive files by keyword or by pasting a Google Drive, Docs, Sheets, or Slides URL.
- Browse a Drive folder tree.
- Fetch a selected Drive file to a destination path inside the task or workspace filesystem.

Notes:
- Google Docs export as `.docx`.
- Google Sheets export as `.xlsx`.
- Google Slides export as `.pptx`.
- Prefer fetching only the files you actually need.
